# 邮件服务系统文档

## 概述

邮件服务系统是游戏中的核心通知和奖励发放系统，负责处理各种类型的邮件发送、接收和管理。系统支持多种邮件类型，包括系统通知、奖励发放、互动邮件等。

## 系统架构

### 1. 核心组件

#### 1.1 邮件发送接口 (IMailSender)
```cpp
class IMailSender
{
public:
    // 错误邮件发送 - 服务内部数据或逻辑错误，必须处理
    virtual void ErrorMailSender(int aiMailID, std::string &aoErrorMsg) = 0;
    
    // 警告邮件发送 - 服务内部数据或逻辑错误，但不影响业务继续执行
    virtual void AlertMailSender(int aiMailID, std::string &aoAlertMsg) = 0;
    
    // 通知邮件发送 - 服务运行状态正常上报
    virtual void NotifyMailSender(int aiMailID, std::string &aoNotifyMsg) = 0;
};
```

```cpp
void adventure_award_email_complex_task::do_rich_text_format_rq(unsigned int _thread_index)
{
    // 设置配置ID和会话ID
    __req.set_config_id(__config_id);
    __req.set_session_id(__unique_id);
    
    // 获取邮件配置
    auto mail_cfg = common.db_conf.get_t_mail_info_config(__config_id);
    if (mail_cfg) {
        __title = mail_cfg->mail_title;
        __lost_time = mail_cfg->lose_time;
        __ext_type = mail_cfg->service_type;
        
        // 处理通配符替换
        const auto &text_start_wildcar = mail_cfg->text_start_wildcard;
        for (auto &wildcard : text_start_wildcar) {
            if (1 == wildcard) {
                auto user = __req.add_users();      
                user->set_wildcard_id(1);
                user->set_user_type(0);
                user->mutable_user()->set_user_id(__user_id);
                break;
            } 
        }
    }
    
    // 开始异步操作
    this->begin_async_operation(0);
    this->begin_rpc_request(0, 0);
    this->end_rpc_request(common.parameter_conf.get_rpc_timeout());
    this->end_async_operation(channel_index);
}
```

**2. 邮件发送到Redis队列**
```cpp
void adventure_award_email_complex_task::do_send_mail_redis(unsigned int _thread_index)
{
    // 构建邮件请求
    __mail_rq.set_to_user(__user_id);
    auto mail_info = __mail_rq.mutable_mail_info();
    
    // 设置发件人信息
    auto from_user = mail_info->mutable_from_user();
    from_user->set_user_id(__user_id);
    from_user->set_user_type(MailBoxBase::NORMAL_USER);
    mail_info->set_title(__title);
    mail_info->set_has_operator(1);
    
    // 设置附件
    auto annex = mail_info->mutable_annex()->Add();
    annex->set_type(MailBoxBase::AnnexType::AnnexType_normal); 
    auto items = annex->mutable_items();
    for (const auto& ic : __award_map) {
        auto item = items->Add();
        item->set_itemid(ic.first);
        item->set_count(ic.second);
    }
    
    // 设置邮件内容
    if (__use_text_build_from_cfg || !__rsp.has_panel()) {
        mail_info->set_body(__common_desc);
    } else {
        MailBoxBase::MailCommonInfo common_info;
        common_info.add_panel()->CopyFrom(__rsp.panel());
        auto common_describe = common_info.SerializePartialAsString();
        mail_info->set_body(common_describe);
    }
    
    // 设置邮件基础信息
    auto mail_base_info = mail_info->mutable_base();
    mail_base_info->set_type(MailBoxBase::MAIL_COMMON);
    mail_base_info->set_mail_id(common.get_nanosecond());
    mail_base_info->set_time(common.get_current_secs());
    mail_base_info->set_expires(common.get_current_secs() + __lost_time);
    mail_base_info->set_source_type(MailBoxBase::ENVELOPE);
    mail_base_info->set_mail_content_type(MailBoxBase::CONTENT_TEXT_AND_AWARD);
    mail_base_info->set_from_server("19647人偶押镖服务");
    
    // 获取Redis上下文并发送
    __RedisMgrImpl::__RedisContext context = common.redis_mgr.get_redis_context_by_type(enum_redis_type_mail_send_que); 
    if (!context) {
        LOG_TRACE(LOG_ERR, __user_id, __FUNCTION__, 
                 __LINE__ << " 镖车奇遇 获取信封redis队列上下文失败!!");
        finish();
        return;
    }
    
    __mail_req_str = __mail_rq.SerializePartialAsString();
    
    // 开始异步操作
    unsigned long long int uq_id = common.get_nanosecond();
    begin_async_operation(uq_id);
    set_channel_type(0);
    set_channel_range(GET_CHANNEL_INDEX_FOR_WRITE_REDIS(0)); 
    begin_redis_command(0,0);
    
    // 发送到Redis队列
    if (redis_command(1, 0, context, "lpush ppworld:mail:send:queue %b", __mail_req_str.data(), __mail_req_str.size())) {
        clear_all_async_operation();
        LOG_TRACE(LOG_ERR, __user_id, __FUNCTION__, 
                  __LINE__<< " 镖车奇遇 信封push redis失败!!");
        finish();
        return;
    }
    
    end_redis_command(common.parameter_conf.get_redis_timeout());
    end_async_operation(GET_CHANNEL_INDEX_FOR_WRITE_REDIS(0));
}
```

#### 3.2 通用消息发送
```cpp
void send_common_use_message_complex_task::do_send_message(unsigned int _thread_index)
{
    if(__msg_type == 16252) {
        // 发送信封队列
        __RedisMgrImpl::__RedisContext context = common.redis_mgr.random_context(enum_redis_type_mail_send_que);
        if (!context) {
            LOG_ERROR(AFLOG_FL_LESS, "failed to fetch context of redis");
            return;
        }
        MailBoxSvr::SvrSendMailRQ* const svr_send_mail_msg = __payload.convert_to<MailBoxSvr::SvrSendMailRQ>();
        const std::string& msg_str = svr_send_mail_msg->SerializePartialAsString();
        if (redis_command(context, "LPUSH ppworld:mail:send:queue %b", msg_str.data(), msg_str.size())) {
            LOG_ERROR(AFLOG_FL_LESS, "push msg failed.");
        } else {
            if (common.debug_info) {
                LOG(AFLOG_FL_LOT)AFLOG_WRITE("Msg", svr_send_mail_msg->ShortDebugString().c_str(), AFLOG_NAME_DESCRIBE, "push msg done");
            }
        }
    } else {
        // 其他类型消息处理
        __RedisMgrImpl::__RedisContext context = common.redis_mgr.random_context(enum_redis_type_maze_task_escort_complete_queue);
        if (!context) {
            LOG_ERROR(AFLOG_FL_LESS, "failed to fetch context of redis");
            return;
        }
        if (redis_command(context, "LPUSH maze:task:escort:complete:queue %s", __str_msg.c_str())) {
            LOG_ERROR(AFLOG_FL_LESS, "push msg failed.");
        } else {
            if (common.debug_info) {
                LOG(AFLOG_FL_LOT)AFLOG_WRITE("Msg", __str_msg.c_str(), AFLOG_NAME_DESCRIBE, "push msg done");
            }
        }
    }
    
    finish();
}
```

### 11. 邮件系统特性

#### 11.1 支持的功能
- **多种邮件类型**：系统邮件、战斗邮件、组队邮件等
- **富文本支持**：支持颜色、字体、字号等样式
- **附件系统**：支持物品、宝箱、礼包等附件
- **广播功能**：支持家族、联盟、地图广播
- **投票功能**：支持问卷调查和投票
- **跳转功能**：支持页面跳转和操作
- **过期机制**：支持邮件过期时间设置
- **一键领取**：支持批量领取奖励

#### 11.2 邮件状态管理
- **未读/已读**：`mail_has_read` 字段控制
- **已处理/未处理**：`has_operator` 字段控制
- **过期时间**：`expires` 字段控制
- **广播状态**：`broadcast_flag` 字段控制

### 12. 邮件系统流程

#### 12.1 邮件发送流程
1. **创建邮件任务** - 根据业务需求创建对应的邮件任务
2. **富文本格式化** - 调用富文本服务进行内容格式化
3. **构建邮件结构** - 设置邮件基础信息、内容、附件等
4. **发送到队列** - 将邮件推送到Redis队列
