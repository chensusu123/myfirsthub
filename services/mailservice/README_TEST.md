# 邮件服务测试脚本使用说明

## 概述
这个测试脚本集包含了邮件服务的完整测试套件，用于验证邮件服务的各项功能是否正常工作。

## 文件结构
```
services/mailservice/
├── test_mail_service.bat          # 主测试脚本
├── test_basic_mail.go             # 基础邮件功能测试
├── test_config_mail.go            # 配置功能测试
├── test_attachment_claim.go       # 附件领取功能测试
├── test_batch_mail.go             # 批量邮件功能测试
├── test_advanced_mail.go          # 高级邮件功能测试
├── test_delete_restrictions.go    # 删除限制功能测试
├── test_bag_integration.go        # 背包集成功能测试
└── test_monitor.go                # 监控功能测试
```

## 使用方法

### 1. 运行完整测试套件
```bash
# 在 Windows 命令行中运行
test_mail_service.bat
```

### 2. 运行单个测试
```bash
# 基础邮件功能测试
go run test_basic_mail.go 10001 20001 0

# 配置功能测试
go run test_config_mail.go 10001 1

# 附件领取功能测试
go run test_attachment_claim.go 10001 20001 0

# 批量邮件功能测试
go run test_batch_mail.go 10001

# 高级邮件功能测试
go run test_advanced_mail.go 10001

# 删除限制功能测试
go run test_delete_restrictions.go 10001 20001 0

# 背包集成功能测试
go run test_bag_integration.go 10001

# 监控功能测试
go run test_monitor.go
```

## 测试参数说明

### 基础参数
- `userId`: 测试用户ID (例如: 10001)
- `mailId`: 测试邮件ID (例如: 20001)
- `label`: 邮件标签 (0=系统邮件, 1=家族邮件, 2=联盟邮件)
- `configId`: 配置ID (1=系统邮件, 2=奖励邮件, 3=活动邮件)

### 测试数据
- 测试用户ID: 10001, 10002, 10003
- 测试邮件ID: 20001, 20002, 20003
- 测试物品ID: 1001, 1002, 1003, 1004, 1005, 1006
- 测试配置ID: 1, 2, 3

## 注意事项

### 1. 环境要求
- Go 1.18+
- Windows 10+
- 邮件服务依赖的数据库和Redis服务需要运行

### 2. 测试数据
- 测试脚本会创建测试数据，不会影响生产环境
- 测试完成后会自动清理测试数据

### 3. 错误处理
- 如果某个测试失败，脚本会停止并显示错误信息
- 可以单独运行失败的测试进行调试

### 4. 性能测试
- 批量测试会测试大量数据的处理能力
- 背包空间测试会测试边界条件
